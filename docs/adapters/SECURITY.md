# Безопасность адаптеров

## Граница доверия

Plugin Manager загружает только директории из явно заданного локального `ADAPTERS_DIR`. Manifest не является доказательством безопасности: executable должен быть установлен из источника, которому доверяет владелец машины. Автоматическая загрузка кода из сети и административные API установки не реализованы.

Отдельный процесс и урезанное окружение **не являются OS sandbox**. Процесс наследует права пользователя, который запустил CARVION. Текущая система не гарантирует изоляцию от файловой системы, сети или локальных устройств средствами ОС. Поэтому локальный каталог должен считаться доверенным.

## Контроль ядра

- Core решает, какой зарегистрированный adapter ID вызвать и когда запускать процесс.
- Реальные device handles не передаются; пользовательский UI не обращается к плагинам напрямую.
- PostgreSQL pool, DSN и credentials не передаются в аргументах или переменных окружения адаптера.
- Входные данные передаются только в JSON-RPC payload; файловые пути к исходному ресурсу не выдаются.
- Core ограничивает размеры frames/manifest, время вызова и параллелизм, проверяет RPC envelope и result types.
- Executable должен разрешаться внутрь директории плагина; ссылки/пути наружу отклоняются.
- Только manifest с согласованными API/SDK версиями и точным `GetInfo` допускается к регистрации.

## Статусы и выводы

`available` означает, что последний процессный вызов завершился корректно; это не проверка подписи или доверия к коду. `unavailable` отражает последний RPC/process failure. Результат vehicle compatibility отдельно использует `supported`, `unsupported` и `unknown`; технический сбой нельзя отображать как несовместимость.

Неизвестная identity или firmware должна оставаться `unknown`, пока нет достаточных проверяемых данных. Demo adapter использует только тестовые фикстуры и не заявляет поддержку Geely или других реальных марок.

## Не реализовано

Подпись и provenance package, OS sandbox, network policy, privilege separation и Hub-based distribution требуют отдельного threat model и являются будущими задачами. Не использовать SDK для обхода защит, несанкционированного доступа к автомобилю или установки firmware.
