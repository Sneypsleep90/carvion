# Безопасность Geely Research Mode

## Границы данных

- Источник выбирается пользователем в Desktop; приложение читает только содержимое переданных файлов.
- Валидация JSON строгая: ограничение 128 KiB, UTF-8, дубликаты/неизвестные поля отклоняются. VIN-подобные последовательности и известные credential assignments не принимаются.
- Desktop проверяет размер файла по `File.size` до чтения содержимого; лимит профиля и ресурса — 128 KiB. Core повторно проверяет размер и UTF-8.
- Ресурс проверяется на UTF-8, basename и один из объявленных форматов.
- В JSON-RPC передаются содержимое и имя файла, но не локальный filesystem path.
- Адаптер не получает PostgreSQL DSN/credentials, доступ к файлам, сети, устройству, CAN/OBD/ADB, установке или записи firmware.
- Адаптер запускается только из доверенного локального каталога. Отдельный процесс сам по себе не является OS sandbox.

## Диагностический отчёт

Отчёт содержит версию схемы, импортированные поля профиля с происхождением, compatibility status/reason, ссылки на статические публичные источники, basename ресурса, SHA-256 и ключи строк. Он не содержит полного локального пути или исходного XML/JSON содержимого. Profile schema запрещает VIN/credentials и неизвестные поля; значения с распознанным VIN-подобным или credential-assignment шаблоном отклоняются.

Отчёт не является доказательством соединения с автомобилем и не подтверждает применимость ресурсов. `unknown` означает отсутствие точной проверенной записи. Общие продуктовые сведения из каталога источников не могут обосновать `supported` или `unsupported`: правило должно ссылаться на отдельно одобренное точное доказательство комбинации.

## Не реализовано

Нет сетевой загрузки адаптеров/данных, передачи raw firmware images, OS sandbox, установки, модификации, обхода защиты или прямой автомобильной диагностики.
