## Правила ведения

- Для технического утверждения сохраняйте точную ссылку, издателя, дату публикации, дату получения, область применимости и степень подтверждения.
- Разделяйте прямой факт, вывод и неизвестное; не переносите сведения между модельными годами и рынками без источника.
- Заполняйте идентификаторы платформы, аппаратную ревизию и build только по подтверждённым данным.
- Не включайте персональные данные, секреты, firmware images без прав или инструкции по обходу защиты.
- Источник общего описания не является правилом совместимости. При отсутствии полного проверенного tuple используйте `unknown`.
