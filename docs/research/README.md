# Индекс исследований автомобильных платформ

## Текущее состояние

Подтверждённых исследований реальных автомобильных платформ в репозитории нет. Demo profiles synthetic. Источники, firmware identifiers и compatibility claims для Geely или других производителей отсутствуют. Этот каталог пока является индексом, а не доказательством совместимости.

## Требования к будущему исследованию

- Сохранять точные ссылки, название документа/релиза, издателя, дату публикации и дату доступа.
- Разделять подтверждённые факты, выводы и неизвестное; выводы помечать явно.
- Фиксировать модель автомобиля, infotainment platform, hardware revision и software build только если источник это подтверждает.
- Описывать способ получения данных, ограничения доступа и правомерность использования.
- Не публиковать секреты, персональные данные, firmware images без прав или инструкции по обходу защиты.
- Не превращать общие заявления или совпадение версии в утверждение о совместимости.
- При недостатке доказательств оставлять результат `unknown`.

```text
Выводы (отмечены отдельно):

Разрешённый способ анализа:
Ограничения и риски:

Проверяющий и дата review:
```

**Кандидат roadmap:** Geely Research Adapter. Исследование не начато, поддержка Geely не заявлена. Сначала определить платформу, источники и разрешённые границы; затем создавать отдельный документ в этом каталоге.
